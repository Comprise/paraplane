# internal/track
Сводит коммиты, состояние и `--done` в готовый прогресс плана и счётчики сделанного.

## Назначение
- Одно место, где решается, что сделано в плане (спека 2026-10-23 §4): коммиты волн, этапов и задач, задачи вернувшихся субагентов из состояния, `--done`. Через него прогресс рисуют и CLI (`paraplane progress`), и хук прогресса.

## Публичный API / точки входа
- `PlanStatus(root, planRel, p, extra) (Status, error)` — `Status{Text, Waves, Tasks}`: вывод `progress.RenderFrom` с предупреждениями о потерянных трейлерах в конце (`warning: wave|task <id> commit <hash>: trailers not in the last paragraph`), число сделанных волн и задач.

## Структура и поток данных
- `gitx.PlanCommits` → волны и задачи из трейлеров; `state.Load(gitx.GitDir)` → `Closed` с проверкой «`head` записи — предок текущего `HEAD`» (`gitx.IsAncestor`, с кешем на вызов; пустой `head` всегда годен); `extra` дописывается в конец закрытых.
- `count` повторяет правило `RenderFrom`: волны по порядку сделаны, пока закрыты (коммит или все задачи); первая незакрытая добавляет свои сделанные задачи.

## Инварианты и подводные камни
- Нет каталога git (`GitDir` с ошибкой) — состояние просто не читается; ошибка `PlanCommits` (нет git, старый git) возвращается.
- Записи состояния после `git reset` на более ранний коммит не считаются.

## Связи (зависит от / используется в)
- Зависит от: `internal/gitx`, `internal/state`, `internal/progress`, `internal/plan`, `internal/textx`.
- Используется в: `cmd/paraplane/progress.go`, `internal/hooks` (хук прогресса).
