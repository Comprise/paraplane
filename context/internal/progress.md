# internal/progress
Рендер прогресса плана: шапка 72 колонки, полоса задач, строка на волну с эмодзи-квадратами, предупреждения.

## Назначение
- Текст для `paraplane progress <file>`: состояние волн плана по коммитам с трейлером `Paraplane-Wave` (спецификация п. 7.1).
- Цвет передаётся эмодзи (🟩 🟨 ⬜), т.к. ANSI в чате не рисуется.

## Публичный API / точки входа
- `Render(p *plan.Plan, name string, done []string) string` — `name` — имя файла плана, `done` — id волн, у которых есть коммит. Пакет не ходит в git и в файловую систему.

## Структура и поток данных
- Состояние по порядку плана: волны с коммитом до первой без коммита — `done`; первая без коммита — `running`; все дальнейшие — `waiting`, даже если коммит у них есть.
- Коммит волны после `running` — `warning: wave <id> was committed before <running id>`; id из `done`, которого нет в плане, — `warning: commit for unknown wave <id>` (один раз на id).
- Процент и полоса считаются по задачам `done`-волн с округлением вниз; `N` в `wave N/M` — номер `running`, при всех `done` — `M`.
- Колонки строки волны: id, квадраты (не больше 12, дальше ` +N`), `d/n`, метка (дополнена до 9), id задач; хвостовые пробелы срезаются.

## Инварианты и подводные камни
- Каждая строка не шире `lineWidth` = 72 колонки — это проверяют тесты; ширину считает `width`.
- `width` считает двухколоночными только 🟩 🟨 ⬜, любой другой символ (включая CJK и прочие эмодзи из id) — одна колонка.
- Все id и имя файла проходят через `textx.Line` (управляющие символы вычищаются); `textx.Line` не считает добавленный `…` в лимит, отсюда `room-1` и константы `*RunesBeforeEllipsis`.
- id волн режутся до 32 рун; дальше — только если фиксированные колонки выталкивают строку за 72, и тогда `midCut` сохраняет начало и конец, чтобы id, различающиеся хвостом, оставались различимы.
- Список id задач обрезается `…` по остатку ширины; при нулевом остатке не выводится вовсе.
- Строки предупреждений обрезает `capLine` до 72 колонок.

## Связи (зависит от / используется в)
- Зависит от: `internal/plan` (`Plan`, `Waves`, `Tasks`), `internal/textx`.
- Используется в: `cmd/paraplane/progress.go` (`runProgress`: план валидируется, коммиты берутся из `gitx.WaveCommits`).
