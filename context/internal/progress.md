# internal/progress
Рендер прогресса плана: шапка 72 колонки, полоса задач, строка на волну с эмодзи-квадратами, предупреждения.

## Назначение
- Текст для `paraplane progress <file>` и хука прогресса: состояние волн плана по коммитам, `--done` и вернувшимся субагентам (спецификация п. 7.1).
- Цвет передаётся эмодзи (🟩 🟨 ⬜), т.к. ANSI в чате не рисуется.

## Публичный API / точки входа
- `Input{CommittedWaves, CommittedTasks, Closed, Recorded}` — что известно сделанным: волны и задачи из трейлеров коммитов, `Closed` — задачи из `--done`, `Recorded` — задачи вернувшихся субагентов из файла состояния. Три списка задач считаются одинаково, различаются только предупреждения (A-M6).
- `Count(p, Input) Counts` — единственное правило «что сделано» (A-M3): `Counts{Waves, Tasks int; State []WaveState}` — число `done`-волн, число сделанных задач и состояние каждой волны (`Done`, `Running`, `Waiting`). `track` берёт числа отсюда, а не считает сам.
- `RenderFrom(p, name, Input) string` — текст прогресса из `Count`; `name` — имя файла плана. Пакет не ходит в git и в файловую систему.
- `Render(p, name, done)`, `RenderClosed(p, name, done, closed)` — устаревшие обёртки над `RenderFrom` до R13.

## Структура и поток данных
- `Count`: по порядку плана волна `done`, пока у неё есть коммит или все её задачи (хотя бы одна) сделаны; первая другая — `running` и добавляет свои сделанные задачи; все дальнейшие — `waiting`, их задачи не считаются, даже если сделаны.
- `RenderFrom` = `writeHeader` (шапка и полоса) + `writeRows` (строки волн) + `warnings`; всё из `Count`, правило в одном месте.
- Сделанные задачи `running`-волны рисуются 🟩 в порядке задач, остальные — 🟨.
- Предупреждения по порядку, каждое один раз на id своего вида: коммит волны после `running` — `warning: wave <id> was committed before <running id>`; коммит неизвестной волны — `warning: commit for unknown wave <id>`; закоммиченная задача `waiting`-волны — `warning: task <id> was committed before <running id>`; id из `--done` не из плана — `warning: --done <id> is not a task of the plan`, задача `waiting`-волны — `warning: --done <id> is in waiting wave <W>`; задача из `Recorded` в `waiting`-волне — `warning: task <id> finished before <running id>`, если о ней ещё не предупредили как о закоммиченной или `--done`. id из `Recorded`, которых нет в плане, молча не считаются (хук записывает только задачи плана).
- Процент и полоса — по `Counts.Tasks` с округлением вниз; `N` в `wave N/M` — номер `running`, при всех `done` — `M`.
- Колонки строки волны: id, квадраты (не больше 12, дальше ` +N`), `d/n`, метка (дополнена до ширины самой широкой метки, `labelWidth`), id задач; хвостовые пробелы срезаются. Квадраты и метки — таблицы пакета `squares`, `labels`.

## Инварианты и подводные камни
- Каждая строка не шире `lineWidth` = 72 колонки — это проверяют тесты; ширину считает `width`.
- `width` считает двухколоночными широкие руны (`wide`: блоки East Asian Wide/Fullwidth — CJK, хангыль, кана, полноширинные формы — и эмодзи, включая 🟩 🟨 ⬜), остальные — одна колонка. Без внешних модулей: таблица диапазонов своя, комбинирующие знаки считаются за одну колонку.
- Имя файла режется по колонкам (`cutWidth`), поэтому шапка остаётся 72 колонки и с CJK в имени (L12).
- Все id и имя файла проходят через `textx.Line` (управляющие символы вычищаются); `textx.Line` и `cutWidth` не считают добавленный `…` в лимит, отсюда `room-1` и константы `*RunesBeforeEllipsis`.
- id волн режутся до 32 рун; дальше — только если фиксированные колонки выталкивают строку за 72, и тогда `midCut` сохраняет начало и конец, чтобы id, различающиеся хвостом, оставались различимы.
- Список id задач обрезается `…` по остатку ширины (по рунам: id задач — ASCII по грамматике); при нулевом остатке не выводится вовсе.
- Строки предупреждений обрезает `capLine` до 72 колонок.

## Связи (зависит от / используется в)
- Зависит от: `internal/plan` (`Plan`, `Waves`, `Tasks`), `internal/textx`.
- Используется в: `internal/track` (`PlanStatus`: коммиты из git, записи состояния, `--done`), через него — `cmd/paraplane` (`progress`) и хук прогресса.
