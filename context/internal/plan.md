# internal/plan
Извлекает блок ```paraplane из Markdown и строго разбирает YAML в Plan с лимитами и типизированными ошибками.

## Назначение
- Единственная точка чтения плана: CLI, хуки, `rules`, `layout`, `progress` получают `*Plan` только отсюда.
- Семантику (id, пути, depends, gate) не проверяет — это `internal/rules`.

## Публичный API / точки входа
- `Load(md)` — `Extract` + `Parse`; обычный вход, без дедлайна.
- `LoadWithin(md, deadline)` — то же с дедлайном проверки: просроченный (до разбора или сразу после него) → `ErrDeadline`; нулевой = без лимита. Декодер YAML не прерывается, вход ограничен `MaxBlock`.
- `Extract(md)` → `Block{Body, Start, End}`; ошибки `ErrNoBlock`, `ErrManyBlocks`.
- `Parse(body)` → `*Plan` или `*SyntaxError` / `*LimitError` / `*SchemaError`.
- `(*Plan).Tasks()` — все задачи в порядке автора; указатели внутрь `p`.
- Лимиты: `MaxBlock` 256 KiB, `MaxTasks` 500, `MaxPaths` 100 на задачу (owns + reads), `MaxTotalPaths` 2000.

## Структура и поток данных
- `Extract` идёт по строкам; содержимое других fenced-блоков не сканируется, поэтому пример ```paraplane внутри более длинного ограждения (````) игнорируется.
- Блок плана — ограждение, у которого первое слово info-строки ровно `paraplane`; ``` и `~~~` оба допустимы, отступ 0–3 пробела.
- `Parse`: один декодинг в промежуточную структуру с `Version *int`, `KnownFields(true)` (неизвестный ключ — ошибка), затем проверка второго YAML-документа, лимитов, версии. Классификацию ошибок библиотеки делает одна функция `decodeError`; `TestDecodeErrorKinds` фиксирует тексты сообщений по одному случаю на вид ошибки.

## Инварианты и подводные камни
- Различение ошибок важно для `rules.Check`: `SchemaError` → E1, всё остальное (нет блока, два блока, синтаксис, лимит) → E0.
- `version` отсутствует или `1` — допустимо; явный `version: 0` отвергается по `*int` (nil — ключа нет), без повторного разбора.
- Несколько YAML-документов (`---`) в блоке — `SyntaxError`.
- Сообщения YAML сводятся в одну строку (`oneLine`); к типичным ошибкам незакавыченных глобов (`*`, `[`) добавляется подсказка `; quote glob patterns`.
- Незакрытое ограждение плана тянется до конца документа.
- `Block.Start`/`End` — абсолютные смещения в исходном `md` (BOM в начале пропускается, но учитывается в смещениях).
- При отступе ограждения 1–3 `Body` — копия с убранным отступом (табы по 4 колонки), число строк сохраняется; при отступе 0 — срез `md`, не копия.
- `Tasks()` возвращает указатели внутрь плана: изменения через них меняют сам план.
- Лимиты защищают хуки от враждебного плана; проверка ведётся до семантики.

## Связи (зависит от / используется в)
- Зависит от: `go.yaml.in/yaml/v3`.
- Используется в: `internal/rules`, `internal/layout`, `internal/progress`, `internal/hooks`, `cmd/paraplane` (audit).
