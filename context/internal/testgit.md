# internal/testgit
Хелперы git для тестов других пакетов: изоляция окружения, временный репозиторий, поддельный старый git, программа-маркер.

## Назначение
- Заменяет разрозненные самодельные хелперы (`testEnv`, `git`, `initRepo`, `gitRun`) одним набором: тесты не читают глобальный конфиг git и не зависят от `GIT_DIR`, `GIT_INDEX_FILE`, `GIT_WORK_TREE`, которые выставляет хост (например git hook).

## Публичный API / точки входа
- `Env()` — `os.Environ()` без переменных `GIT_*`, плюс `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=os.DevNull`, автор и коммитер.
- `Isolate(t)` — снимает все `GIT_*` из окружения процесса через `t.Setenv` (восстанавливаются по окончании теста) и отключает глобальный и системный конфиг.
- `Run(t, dir, args...)` — `git -C dir args` под `Env()`, возвращает stdout без хвостовых пробелов; ошибка валит тест.
- `Init(t)` — пустой репозиторий (ветка `main`) во временном каталоге.
- `Commit(t, dir, file, msg)` — пишет файл и коммитит с темой `msg`.
- `FakeOldGit(t)` — каталог с обёрткой `git`, которую кладут первой в `PATH`: она сообщает `git version 2.34.1` на подкоманду `version` или `--version`, в том числе после глобальных опций (`-C dir`, `-c k=v`, `--git-dir=…`, как вызывает gitx), и убирает `GIT_NO_LAZY_FETCH`, остальные вызовы передаёт настоящему git.
- `MarkerProgram(t)` — `(cmd, marker)`: командная строка для `sh` вида `TESTGIT_MARKER='<marker>' '<exe>' -test.run=^$`, которая перезапускает тестовый бинарник и создаёт файл `marker`. Нужна, чтобы проверять, что git не запускает программу из конфига, и на Windows тоже.

## Инварианты и подводные камни
- Программа-маркер работает через `init()` пакета: тестовый бинарник, импортирующий `testgit`, при `TESTGIT_MARKER` создаёт файл и завершается до запуска тестов. Команда, которую возвращает `MarkerProgram`, самодостаточна: переменная `TESTGIT_MARKER='<marker>'` стоит в самой командной строке, поэтому маркер создаётся, даже если вызывающий код очистил окружение перед запуском git (отрицательная проверка «git не запустил программу» не проходит вхолостую). Пути записаны с прямыми слэшами.
- `FakeOldGit` — POSIX-скрипт; на Windows вызывает `t.Skip`. Настоящий git ищется через `exec.LookPath` в момент вызова, до подмены `PATH`.
- `Isolate` меняет окружение процесса, поэтому несовместим с `t.Parallel()`.
- Сборка проверена для linux, darwin и windows (`GOOS=windows go vet`).

## Связи (зависит от / используется в)
- Зависит только от стандартной библиотеки и `git` в `PATH`.
- Используется в тестах `internal/gitx`, `internal/hooks`, `internal/track`, `cmd/paraplane` (после переноса на него).
