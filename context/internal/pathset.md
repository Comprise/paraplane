# internal/pathset
Валидирует пути плана и консервативно решает, могут ли два глоба описать один файл (без учёта регистра).

## Назначение
- Ядро правил E2/E4/E5/E6: ответ «может ли пересекаться» без обращения к ФС.
- Допускаются ложные срабатывания, пропуски — никогда (спецификация, п. 4.1, 4.2).

## Публичный API / точки входа
- `Clean(p)` — проверка и `path.Clean`; все остальные функции ожидают уже очищенные шаблоны.
- `Overlap(a, b)` — эталонный API; `Compile(p).Overlaps(Compile(q))` — то же для массовых проверок (тесты держат их равными).
- `Touches(owns, hot)` — задевает ли задача горячий шаблон.
- `Match` — `doublestar.Match`, неверный шаблон не совпадает ни с чем; с учётом регистра.
- `HasMeta`, `SpansSegments` — признаки шаблона.
- Константы: `MaxPatternLen` 256 рун, `MaxBraceGroups` 8.

## Структура и поток данных
- `Clean` отвергает: пустой путь, `\`, абсолютный путь и букву диска, `..` (в том числе альтернативу `{..}`), `/` внутри `{}` и `[]`, отрицание `[!…]`/`[^…]`, диапазоны класса, покрывающие `/`, раскрытие скобок больше 256 вариантов, корень `.`.
- `Overlaps`: общий литеральный префикс сегментов сравнивается первым; затем правила п. 4.1 — литерал/литерал, литерал/шаблон через `Match`, «растягивающиеся» шаблоны (`SpansSegments`) — только по префиксу, иначе посегментно.
- Регистр: литералы приводятся `foldRune` к минимальной руне орбиты `unicode.SimpleFold`; шаблоны — `foldPattern`, классы переписываются в класс свёрнутых рун.

## Инварианты и подводные камни
- Ограничения `Clean` на `{}`/`[]` гарантируют, что каждый сегмент шаблона без `**` и без `*` рядом с `{`, `,`, `}` покрывает ровно один сегмент пути; на этом держится посегментное правило 3. Ослабление `Clean` ломает `Overlap`.
- `*` вплотную к скобочной пунктуации (`{*,a}*`) при раскрытии может склеиться в `**`, поэтому такие шаблоны считаются растягивающимися.
- Лимит раскрытия скобок нужен потому, что один `doublestar.Match` на сотнях альтернатив может идти десятки секунд и не прерывается дедлайном.
- Класс больше 256 рун при свёртке заменяется на `?` — только расширение, корректность сохраняется.
- `foldCache` — глобальный кэш под мьютексом (до 4096 записей, сбрасывается целиком); только для шаблонов с `[`.
- `Overlap` и `Touches` не учитывают регистр (macOS/Windows), `Match` учитывает — аудит A1 сравнивает с учётом регистра.
- Unicode-нормализация (NFC/NFD) не выполняется.
- `Touches`: широкий шаблон (`internal/**`) не задевает литеральный горячий файл, если тот не назван; шаблон без `**` (`web/*.json`) не задевает горячий шаблон — горячие файлы называют литералом.

## Связи (зависит от / используется в)
- Зависит от: `github.com/bmatcuk/doublestar/v4`.
- Используется в: `internal/layout` (Compile/Overlaps/Touches), `internal/rules` (Clean, HasMeta, Match), `internal/config` (Clean для `plans_dir` и списков шаблонов), `internal/hooks` (Match).
