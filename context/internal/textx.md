# internal/textx
Очистка недоверенного текста перед выводом: `Line` — одна строка по рунам, `Block` — многострочный текст по байтам.

## Назначение
- Любой текст из плана, конфига, ошибок YAML или git, попадающий в терминал или в контекст Claude, проходит через этот пакет: так ANSI-последовательности, bidi-символы и переводы строк не ломают вывод и не подделывают строки хуков.

## Публичный API / точки входа
- `Line(s, max)` — заменяет `\n` пробелом, лимит `max` в рунах.
- `HasControl(s)` — есть ли в `s` руна, которую `Line`/`Block` удалили бы или заменили пробелом (управляющие, Zl/Zp, Cf); тот же предикат `unsafe`, что в `sanitize`. Использует `config` для `default_gate`.
- `Block(s, max)` — сохраняет `\n`, лимит `max` в байтах, режет по границе руны.

## Инварианты и подводные камни
- `\r`, `\t`, U+2028, U+2029 (и `\n` в `Line`) становятся пробелом; прочие управляющие символы (`unicode.IsControl`) и format-символы (категория Cf: bidi, zero-width) удаляются.
- При обрезке добавляется `…`, который в `max` не считается: `Line` может вернуть `max+1` рун, `Block` — `max` байт плюс 3 байта `…`. Вызывающий код, считающий ширину, должен учитывать это сам (см. `internal/progress`).
- Отрицательный `max` трактуется как 0: результат — `…` для непустого `s`.
- Ширину в колонках терминала пакет не считает — только руны или байты.

## Связи (зависит от / используется в)
- Зависит только от стандартной библиотеки.
- Используется в: `internal/progress`, `internal/hooks` (`plan_text.go`, `post_tool_use.go`, `session_start.go`), `cmd/paraplane` (`check.go`, `audit.go`, `main.go`).
