# internal/ids
Единая грамматика идентификаторов задач и волн: одна константа вместо копий регулярки в разных пакетах.

## Назначение
- Идентификатор плана, аргументы CLI `--done`/`--forget`, списки волн, регулярка автоодобрения и трейлеры коммитов используют одну грамматику `[A-Za-z][A-Za-z0-9_.-]{0,31}` — расхождений между проверкой и разбором быть не может.

## Публичный API / точки входа
- `Pattern` — исходник регулярки одного идентификатора (без якорей), для встраивания в другие выражения.
- `ListPattern` — `Pattern(,Pattern)*`, список через запятую.
- `Valid(s)` — `s` целиком является одним идентификатором.
- `ParseList(s)` — делит по запятой; `ok == false`, если любая часть невалидна или пуста (`T1,`, `,T1`, `T1,,T2`, пустая строка).

## Инварианты и подводные камни
- Только ASCII: `ä` и прочие не-ASCII буквы не проходят; длина — до 32 символов, первый символ — буква.
- При `ok == true` выполняется `strings.Join(out, ",") == s` (проверяет `FuzzParseList`).
- `Pattern` не содержит `^`/`$`; якоря добавляет вызывающий код. `Valid` якорит сам.

## Связи (зависит от / используется в)
- Зависит только от стандартной библиотеки.
- Потребители переводятся на пакет задачами плана review-fixes (plan, hooks, progress, cmd/paraplane, gitx).
